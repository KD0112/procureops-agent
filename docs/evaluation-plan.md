# Evaluation Plan

## 1. 评测层次

1. 组件：字段提取、目录匹配、检索和计算器
2. 轨迹：模型、工具、重试、审批和证据路径
3. 结果：最终数据库状态和 PO 草稿
4. 安全：越权、注入、跨租户、重复写和过期事实
5. 运行：P50/P95 延迟、模型调用、工具调用和成本

## 2. CI 策略

- 单元与集成测试不得要求真实 API Key。
- FakeModel 返回固定结构化结果。
- Mock Tool 支持成功、超时、限流、永久错误和脏数据。
- 真实模型评测是独立命令，不属于普通 PR 必须条件。

## 4. 后续数据集

第一租户目标 100 条：40 正常、20 模糊、15 工具失败、15 攻击、10 权限审批边界。最终结果以环境数据库真值为准，而不是以模型自评为准。

第二租户固定 20 条附加评测：8 条 IT 正常任务、4 条模糊需求、2 条工具故障、2 条攻击、3 条审批边界和 1 条反向跨租户目录隔离。该套件使用同一个 `EvaluationRunner`，只改变 `tenant_id` 与 Tenant Pack。

外部系统专项不依赖公网：MockTransport 验证请求头、租户、合同版本、错误分类和响应 Schema；独立 FastAPI 沙箱验证 ERP、供应商、物流三套 HTTP 契约与 PO 幂等写入。
