# Threat Model

## 资产

- 租户采购任务、供应商报价和预算
- 用户偏好与个人记忆
- API Key 和服务凭证
- 审批记录、PO 草稿和审计事件
- Prompt、规则、Tenant Pack 和评测数据

## 信任边界

1. 用户上传文件是不可信输入。
2. RAG 文档内容是不可信数据，不是系统指令。
3. 模型输出是不可信提议，必须经过 Schema 和策略校验。
4. 外部工具结果可能过期、缺失或被污染。
5. 审批只能授权精确绑定的不可变请求。

## 主要威胁与控制

| 威胁 | 控制 | 测试点 |
|---|---|---|
| Prompt Injection 诱导调用写工具 | 文档与指令隔离、工具白名单、审批门禁 | SEC-001 |
| 跨租户读取 | RunContext、Repository tenant filter、数据库策略 | SEC-002 |
| 伪造价格或库存 | 动态事实只来自工具、有效期检查 | SEC-003 |
| 重试造成重复 PO | 幂等键和请求哈希冲突检查 | SEC-004 |
| 修改内容后复用旧审批 | `subject_hash` 绑定 | SEC-005 |
| 日志泄漏密钥或采购内容 | 白名单元数据、敏感字段脱敏 | SEC-006 |
| 恶意文件或超大文件 | 类型、大小、页数限制；解析沙箱后置 | SEC-007 |
| 自动学习污染规则 | 候选、离线评测、人工发布 | SEC-008 |

所有高风险不变量采用零容忍门槛。
