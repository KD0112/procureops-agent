# ProcureOps Agent PRD

## 1. 产品目标

将一个或多个 Excel、PDF、图片、文本附件或自然语言采购需求转换为可核验的采购明细，匹配企业目录，查询供应商动态事实，执行成本与风险检查，并在必要审批后创建采购单草稿。

MVP 的业务终点是 `PO_DRAFTED`，不发送真实询价、不提交正式订单、不付款。

## 2. 租户

### 2.1 工程机械配件

- `tenant_id`: `tenant_engineering_machinery`
- 场景：工程机械配件采购
- 单任务：1 至 8 个行项目
- 币种：CNY
- 默认规则：已批准供应商、报价有效期 30 天、替代件人工确认、超预算阻止
- 审批：低于 10,000 元由采购专员确认；10,000 至 50,000 元部门审批；高于 50,000 元部门与合规双审批

权威阈值保存在版本化规则配置中，RAG 仅负责解释制度。

### 2.2 企业 IT 设备

- `tenant_id`: `tenant_enterprise_it`
- 场景：研发终端、服务器、存储、网络、安全与机房设备采购
- 单任务：1 至 8 个行项目
- 币种：CNY
- 默认规则：资产标准优先、报价有效期 14 天、替代规格人工确认、网络与安全设备保留安全评审边界
- 审批：低于 20,000 元由采购专员确认；20,000 至 100,000 元部门审批；高于 100,000 元部门与合规双审批

两个租户复用同一状态机、Harness、Agent、记忆、RAG 治理、审批和评测代码，只替换 Tenant Pack、目录、知识、规则和工具适配器绑定。

## 3. 用户角色

- 业务申请人：创建任务、上传资料、补充信息
- 采购专员：确认匹配、比较供应商、提交审批
- 部门审批人：审批部门采购
- 合规人员：审批高金额、异常低价和未批准供应商
- 目录管理员：维护静态目录和知识文档
- 审计员：只读查看证据、Trace 和版本

## 3.1 任务与附件治理

- 单任务最多上传 5 个附件；单文件最多 10 MiB，合计最多 25 MiB。
- 多附件中的重复采购行按稳定业务键合并，但保留每个文件的字段证据。
- 同一物料在不同附件中数量、单位或设备型号冲突时必须进入 `NEEDS_INPUT`，禁止继续供应商查询和 PO 写入。
- 页面“删除任务”采用软归档：任务从工作台隐藏，待处理 Job 终止，但附件、证据、审批、PO 和追加式审计不物理删除。
- 任务创建人可以归档自己的任务；合规角色可以归档租户内任务。物理删除不在 MVP 范围内。

## 4. MVP 状态机

```text
DRAFT -> INGESTING -> NEEDS_INPUT? -> MATCHING -> SOURCING
      -> CALCULATING -> RISK_REVIEW -> AWAITING_APPROVAL?
      -> APPROVED -> PO_DRAFTED -> COMPLETED
```

非法状态跳转默认拒绝。审批绑定任务版本和采购快照哈希。

## 5. 成功指标

- 行项目提取 Micro-F1 >= 0.95
- Catalog Recall@5 >= 0.95
- 关键字段证据覆盖率 = 100%
- 确定性成本计算正确率 = 100%
- 未审批高风险写操作 = 0
- 重复 PO 草稿 = 0
- 跨租户数据泄漏 = 0
- 中断恢复测试通过率 = 100%

## 6. 暂不实现

- 连接任何未提供 Endpoint、UAT 账号和合同 Schema 的企业生产系统
- 发送真实供应商邮件、提交正式订单或触发付款
- 付款、退款、合同签署
- 生产自动修改 Prompt、规则或代码
- Kubernetes、Docker、WSL2
- 开放互联网供应商爬取

本机已提供 ERP、供应商和物流独立 HTTP 契约沙箱，并提供 `http_enterprise` 适配器 Profile。前者用于证明接口、鉴权、超时、错误分类、证据和幂等设计，不冒充真实厂商生产连接。
